# 02: 应用创建与智能类型路由

**What to build:** 用户输入一句需求即可创建 App，系统自动把需求路由到 HTML、MULTI_FILE 或 VUE_PROJECT。用户可以查看、更新、删除自己的 App，首页展示我的作品与精选作品，并能看到旧应用已有的预览入口。

**Blocked by:** 1

**Status:** ready-for-agent

- [ ] 创建 App 时调用可替换的路由能力，生成合法 codeGenType；路由失败时有确定的安全回退并记录错误。
- [ ] App 的创建、分页查询、详情、更新、删除均校验登录态和所有权，分页响应形状与前端约定一致。
- [ ] 删除 App 会清除数据库记录，并对已有 Workspace、部署产物和封面执行约定的清理流程。
- [ ] 首页与编辑页可展示现有 App；旧应用记录可通过复制后的运行时产物继续预览。
- [ ] 路由提示词资产从缺失状态补齐或重写，并通过脚本化模型测试覆盖三种 codeGenType。
