# 10: 部署封面截图与 COS

**What to build:** 部署完成后系统自动打开分享地址生成截图、上传 COS，并把封面更新到 App 列表；截图失败不会回滚已经成功的部署。

**Blocked by:** 9

**Status:** ready-for-agent

- [ ] 部署成功会触发异步截图任务，用户无需等待截图完成即可拿到分享链接。
- [ ] 截图成功后上传对象存储并更新对应 App 的 cover。
- [ ] 浏览器启动失败、页面超时、上传失败都会记录可诊断错误，且不影响部署状态。
- [ ] 测试通过浏览器与对象存储替身验证成功、超时和上传失败路径。
- [ ] 管理端和首页能看到更新后的封面，未生成时使用稳定占位图。
