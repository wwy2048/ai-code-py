# 14: M2 应用级持久记忆

**What to build:** 同一 App 的后续生成会话可以使用经过管理的持久记忆，减少重复说明；记忆严格按 App 隔离，可由用户查看和清除，并在删除 App 时同步删除。

**Blocked by:** 7

**Status:** ready-for-agent

- [ ] 持久记忆默认关闭，通过 feature flag 或 App 级开关启用。
- [ ] 记忆只从当前 App 的成功 Turn 中提取，不自动注入其他 App 或用户数据。
- [ ] 后续 Turn 能读取命中的记忆，并在上下文预算内限制注入大小。
- [ ] 用户可查看和清除当前 App 的记忆；删除 App 会清理全部关联记忆。
- [ ] 测试覆盖 App 隔离、用户删除、预算限制和关闭开关时的不注入行为。
