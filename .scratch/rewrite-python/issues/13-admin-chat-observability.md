# 13: 管理员会话检查与运行观测

**What to build:** 管理员可以分页查看对话历史，并进入单个 Turn 查看隐藏 Tool 消息、Compaction Summary、模型耗时和错误；用于定位生成问题，但不会暴露密钥或完整大文件正文。

**Blocked by:** 8, 12

**Status:** ready-for-agent

- [ ] 管理员可按用户、App、消息类型和时间筛选对话历史。
- [ ] 单个 Turn 的调试详情能区分 visible 与隐藏消息，并展示工具状态、耗时和截断后的结果预览。
- [ ] 模型调用记录包含耗时、状态、错误和必要关联标识，不包含 API Key、环境变量或完整敏感正文。
- [ ] 普通用户无法读取隐藏运行时消息或观测详情。
- [ ] 前端管理页完成查询与详情展示，测试覆盖权限和数据脱敏。
