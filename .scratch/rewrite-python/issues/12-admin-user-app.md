# 12: 管理员用户与应用治理

**What to build:** 管理员可以分页查询用户、修改用户资料与角色，查询和更新全部 App，管理精选状态与优先级，并删除违规 App。

**Blocked by:** 2

**Status:** ready-for-agent

- [ ] 普通用户访问管理员端点返回明确的权限错误，管理员身份由数据库角色决定。
- [ ] 用户管理支持分页查询、详情、更新和删除，敏感密码字段不会返回前端。
- [ ] App 管理支持分页查询、详情、名称/封面/优先级更新和删除，删除复用统一的产物清理流程。
- [ ] 首页精选列表只展示符合条件的公开 App，并按约定优先级排序。
- [ ] 管理端页面完成对应操作，HTTP seam 测试覆盖角色校验与分页。
