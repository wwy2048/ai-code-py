# 06: VUE_PROJECT 生成与受控构建

**What to build:** 用户生成 Vue 项目后，系统使用固定可信模板完成受控构建，把构建产物用于实时预览；构建失败时，Agent 能收到截断后的错误信息并尝试修复。

**Blocked by:** 4

**Status:** ready-for-agent

- [ ] Agent 只能修改模板允许的页面源码和静态资源，不能修改依赖清单、构建配置或安装任意 npm 包。
- [ ] 构建由受控构建入口执行，不继承服务端密钥，并具备超时、输出上限和失败状态。
- [ ] 构建成功后预览指向 dist 入口；构建失败时不会把半成品误报为成功。
- [ ] 构建错误可以回传给模型，模型修复后最多进行有界次数的重试。
- [ ] 测试覆盖固定模板拒绝越界修改、构建成功、构建失败和超时场景。
