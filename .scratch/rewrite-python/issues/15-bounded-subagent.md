# 15: M2 有界子代理

**What to build:** 主 Agent 可以把一个明确范围的工作委派给一级子代理；子代理在受控目录内读写文件，完成后只返回摘要，解锁更复杂项目的上下文拆分能力。

**Blocked by:** 6

**Status:** ready-for-agent

- [ ] 提供 Subagent Tool，调用时必须声明任务目标和工作目录范围；子代理不能访问 Workspace 外路径。
- [ ] 同一 App 同一时刻最多运行一个子代理，最大嵌套深度为 1，不能创建下一级子代理。
- [ ] 子代理不能执行 shell、不能向用户提问，并具有最大轮数和超时限制。
- [ ] 主 Agent 只接收最终摘要；必要的开始、结束或失败事件通过 External Event 展示给用户。
- [ ] 测试覆盖路径约束、并发拒绝、嵌套拒绝、超时和摘要返回。
