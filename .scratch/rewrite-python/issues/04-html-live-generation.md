# 04: HTML 真模型生成

**What to build:** 用户提交真实需求后，DeepSeek 通过 Anthropic 兼容协议驱动同一条 Agent Runtime，生成可预览的 HTML 网站；模型调用、工具调用和失败恢复对用户表现为稳定的流式生成体验。

**Blocked by:** 3

**Status:** ready-for-agent

- [ ] 真实模型支持流式文本和 tool_use，工具结果能正确回传并继续下一轮，直到产生最终响应。
- [ ] HTML 生成提示词与工具 schema 对齐：模型使用文件工具产出单页网站，而不是依赖 Markdown 代码块解析。
- [ ] 模型超时、限流、连接中断和工具参数错误会得到有界重试或可读失败结果，不会留下无限运行状态。
- [ ] 每次模型调用记录耗时、状态和错误摘要；不记录密钥或完整敏感正文。
- [ ] 真实模型冒烟验证可从一句需求生成并预览 HTML。
