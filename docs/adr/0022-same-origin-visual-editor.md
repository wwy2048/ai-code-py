# 同源 iframe 可视化编辑与元素源码定位

可视化编辑需要主站读取并控制预览 iframe，因此预览必须与主站同源；开发环境通过 Vite 将 `/api` 代理到后端，生产环境由同域反向代理维持这一约束。主站只向 iframe 注入编辑运行时，双方通过带 channel、origin 和 source 校验的 `postMessage` 传递启停指令与选中元素信息。

Vue 项目的 DOM 选择器无法可靠反查编译后的源码，因此在 Vite 构建阶段由自定义插件基于 Vue SFC AST 向原生模板元素注入 `data-ai-source="相对路径:行号"`。选中元素信息作为带固定标记的上下文块加入用户提示词，不新增后端消息字段；聊天界面解析该上下文块并单独展示元素标签。提示词明确声明该属性是构建期内部元数据，要求模型忽略它，不得写入源码，也不得在最终回复中复述。预览静态资源统一返回禁止缓存响应头，且前端在每轮生成完成后通过 `__preview` 版本参数重新加载 iframe，避免继续展示旧产物。
