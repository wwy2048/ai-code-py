# Agent 工具执行采用受控边界

产品按公网多租户模型设计，首版仍采用本地单进程部署。决定不向模型暴露宿主机上的任意 shell，只提供项目内受控的工具与命令执行入口：文件工具限制在应用 Workspace 内，并校验路径解析、符号链接/重解析点、文件大小、数量和执行超时；命令执行只允许明确支持的操作，不继承服务端密钥。V1 的 Vue 项目采用固定可信模板，模型只能修改受控页面源码，不能任意修改 `package.json`、Vite 配置或安装新依赖；模型生成的 Node 配置或 npm scripts 不得直接在宿主机执行。后续若需要完整 shell 或任意 npm 依赖，必须引入容器隔离。

## Status

Accepted（2026-10-30）。

## Consequences

- 运行时能力受控，不能直接复用 minicodex 的全部 CLI 工具行为。
- Vue 构建使用固定可信模板，构建失败日志可以回传给模型用于修复。
- 模型不能通过新增 npm 依赖扩展能力；依赖扩展须通过人工维护模板完成。
- 工具注册表和命令白名单属于安全边界，不能仅为方便调试而开放任意执行。
- 真正的通用 coding agent 能力留到容器化执行环境落地后扩展。
