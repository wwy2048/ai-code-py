# 前端源码内置新仓库并允许演进

原方案把“前端复用零改动”作为硬约束。决定改为从 ai-code 复制前端源码到本仓库，先提交一个可构建的初始基线，之后允许直接修改前端来适配新的 agent 事件、会话和可视化能力。前端不再作为不可修改的外部制品，也不采用 npm 包或 git submodule 的方式引用。

## Status

Accepted（2026-10-30），修订 ADR-0001 的前端复用部分。

## Consequences

- 前端与后端在同一仓库共同演进，可以直接调整 SSE 协议和交互，不再被旧实现细节锁死。
- 初始复制提交用于区分“原样迁移”和“后续主动改动”，便于代码审计与回滚。
- 旧前端仍作为业务、路由和视觉参考，但逐字节兼容不再是验收条件。
