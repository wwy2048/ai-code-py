# 部署截图异步生成并上传 COS

部署请求在数据库提交后立即返回分享 URL，同时调度后台截图任务。每次部署递增 `deploy_revision`，封面任务仅在版本仍匹配时更新 `app.cover`，避免旧截图覆盖新部署。任务使用无头 Chrome 打开部署地址，截图成功后上传腾讯云 COS。截图、浏览器启动、页面超时和上传失败只记录带 `app_id`、阶段与异常类型的日志，不回滚部署、不阻塞用户。

## Status

Accepted（2026-10-31）。

## Consequences

- 部署与封面生成是两条最终一致链路；封面为空或短暂陈旧时前端显示稳定占位图。
- 本地截图文件在上传成功、上传失败或截图失败后都会清理。
- Selenium 与 Chrome 属于后台运行依赖，浏览器不可用时不影响生成网站与分享地址。
- COS 通过 `COS_PUBLIC_BASE_URL` 或桶默认域名构造公开图片 URL；未配置时记录上传失败。
- 服务关闭时等待已调度的截图任务结束，避免数据库连接先于后台任务释放。
- 关闭等待超过配置预算时取消未完成任务；过期或失效部署的上传对象会尝试补偿删除。
