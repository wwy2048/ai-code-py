# 持久记忆严格按 App 隔离

持久记忆通过 `app_memory` 表按 `appId` 隔离，默认由 `APP_MEMORY_ENABLED=false` 关闭。开启后，每个成功 Turn 将当前用户目标与最终结果压缩为一条受限记忆；后续 Turn 在固定字符预算内注入，不读取其他 App 或用户数据。所有者可查看和清除当前 App 记忆，删除 App 时同步物理删除。

## Status

Accepted（2026-10-31）。

## Consequences

- 功能开关关闭时不提取、不注入记忆，也不影响现有会话。
- 注入内容只进入本轮模型消息，不伪装成前端可见历史。
- 记忆按最新记录优先装入预算，单条与总量均受字符上限约束。
- 记忆提取基于成功 Turn，失败 Turn 不产生记忆。
